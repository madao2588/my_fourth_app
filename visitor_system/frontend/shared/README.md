# 前端共享资源说明

## 1. 模块定位

本目录用于存放 Web 和微信小程序共用的前端资料，重点是减少两端联调时的字段歧义和文档分散。

## 2. 当前已包含内容

- [api-contract.md](/d:/projects/my_fourth_app/visitor_system/frontend/shared/api/api-contract.md)
  前后端接口契约说明

## 3. 适合继续放在这里的内容

- 接口契约文档
- 状态枚举说明
- 交互流程图
- 页面原型图
- 公共文案
- 设计规范
- 两端共享的字段映射表

## 4. 使用建议

后续新增接口或字段时，建议优先先更新这里的文档，再同步修改：

- Web 请求层
- 小程序请求层
- 对应页面的渲染逻辑

这样能减少前后端字段不一致带来的返工。
